# fixtures

解析器的回归输入，**不是**插件运行时要用的数据。

| 文件 | 内容 | 用途 |
| --- | --- | --- |
| `pricing.html` | DeepSeek 官方定价页（2026-10 抓取）的一份快照 | 验证 `lib/pricing.js` 能从真实页面结构里解析出逐模型峰谷价、高峰时段与旧模型名别名 |
| `holiday-2026.json` | `timor.tech/api/holiday/year/2026` 的返回快照 | 验证 `lib/holidays.js` 能从那套结构里认出放假日期 |

页面内容与数据版权归 DeepSeek 及原服务方所有，这里只作为**解析兼容性测试的输入**
保存，插件的运行逻辑不依赖它们（线上是直接抓官方页的）。

页面结构变了就该重新抓一份替换掉——解析器宁可整份拒绝（由调用方沿用上一份真实价表），
也不要猜着解析出一个错的价。
